# Architecture Decision Records

Значимые архитектурные решения фиксируются как ADR: одно решение — один файл `NNNN-kebab-title.md` по
[шаблону](../../../.specify/templates/adr-template.md). ADR не редактируются по существу после принятия —
изменение решения = новый ADR со статусом, заменяющим старый (`Superseded by ADR-XXXX`).

Когда нужен ADR: выбор технологии/платформы, изменение принципа конституции, новая интеграция или режим работы,
решение, которое дорого отменить. Команда `/sdd.plan` предлагает ADR, если план принимает такое решение.
