# Нефункциональные требования

> Источник: ТЗ v3 §9 (+ ts-v2 §10 для детализации). Целевые значения подтверждаются на ПСИ с учётом требований ИБ — **ТУ-10**.

| Группа | Требование | Как проверяем |
|---|---|---|
| Производительность | API справочных операций ≤ 200 мс; AI-анализ текстового запроса ≤ 10 с; загрузка интерфейса ≤ 2 с; 500 одновременных пользователей (Этап 1) | Нагрузочный тест (ПС-8) |
| Надёжность | Доступность 99,5%; RTO ≤ 1 ч; ежедневный бэкап; восстановление прерванной сессии диалога | Учения по восстановлению, тест сессии |
| Масштабируемость | Горизонтальное масштабирование сервисов; кэш справочников; очереди для асинхронных операций | Архитектурное ревью |
| Безопасность | СУДИР SSO; RBAC; TLS; шифрование чувствительных данных при хранении; изоляция учётных данных интеграций; журналирование всех действий | Проверка ИБ, ПСИ |
| Деградация | Нет LLM → черновик, шаблонный путь, ручная обработка. Нет внешней системы → отложенная синхронизация без остановки процесса | Тесты с отключёнными адаптерами (режим отказа) |
| Наблюдаемость | Логи, метрики, трассировка; задержки LLM, доля ошибок ИВ, состояние очередей, зависшие заявки, доля ручных корректировок AI | Дашборды до ПСИ |
| Аудируемость | По журналу восстанавливается: исходный запрос, все AI-интерпретации, подтверждения и правки людей, изменения статусов, отправленные артефакты | ПС-7 |
| Удобство (ts-v2) | WCAG 2.1 AA; десктоп — основной, адаптивность для планшета; русский язык, готовность к английскому | UX-ревью |

Каждая спецификация в разделе «Применимые НФТ» перечисляет, какие строки этой таблицы она затрагивает, и как их проверяет.
