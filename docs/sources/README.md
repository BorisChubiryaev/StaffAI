**неподтверждённые сведения**. Их нельзя реализовывать как факт — только через `[NEEDS CLARIFICATION]` в спецификации
и запись в [`../open-questions.md`](../open-questions.md).

## Как добавить новый источник

1. Положите оригинал в `originals/` (или рядом, если это HTML/MD), имя — `NN-kebab-case.ext`, только латиница.
2. Для docx создайте md-версию: `pandoc originals/NN-name.docx -t gfm --wrap=none -o NN-name.md` (с шапкой о происхождении).
3. Добавьте строку в таблицу иерархии и проверьте документ на расхождения с уровнем 1.
4. Обновите синтез в `docs/` и затронутые спецификации; при изменении требований — `docs/requirements/traceability.md`.
