description: Разложить утверждённый план на упорядоченные, трассируемые задачи (tasks.md)
argument-hint: <NNN>
---

Вход: `$ARGUMENTS` — ID спецификации.

1. Прочитай `specs/NNN-*/spec.md`, `plan.md`, `research.md`, `data-model.md`, `contracts/`. Если plan.md не утверждён —
   предупреди пользователя.
2. Скопируй `.specify/templates/tasks-template.md` → `specs/NNN-*/tasks.md`.
3. Сформируй задачи:
   - Группировка по фазам: Подготовка → Фундамент → по одной фазе на каждый пользовательский сценарий в порядке
     приоритета (P1 первым — это MVP фичи) → Завершение.
   - Внутри сценария: **сначала тесты** (приёмочные по Дано/Когда/Тогда, контрактные), затем модели → сервисы →
     API → UI.
   - Каждая задача: `- [ ] T### [P?] [US-NNN-x | FR-NNN-xx] глагол + что — путь/к/файлу`.
   - `[P]` только если задача трогает другие файлы и не зависит от незавершённых.
   - Размер: 0.5–1 день или одна логичная единица для ИИ-агента.
   - Обязательно: тесты режимов отказа зависимостей; eval для AI; обновление docs (события, глоссарий, трассировка).
4. Проверь покрытие: у каждого FR и сценария есть хотя бы одна задача; у каждой задачи — ссылка. Непокрытое — перечисли.
5. Добавь раздел «Зависимости» и контрольные точки после каждого сценария.

Отчёт: число задач по фазам, что можно делать параллельно, предлагаемый MVP-срез (обычно US-1). Следующий шаг —
`/sdd.implement NNN`.
