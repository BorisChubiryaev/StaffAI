Требования ТЗ ↔ спецификации — [docs/requirements/traceability.md](../docs/requirements/traceability.md).

## Реестр спецификаций

Обновляйте статус здесь при каждом его изменении в `spec.md`.

## Как создать спецификацию

```text
/sdd.specify 002-event-log-audit            # по ID из реестра
/sdd.specify "Нужна возможность …"          # новая фича — команда предложит номер
```

Без Claude Code: скопируйте `.specify/templates/spec-template.md` в `specs/NNN-name/spec.md` и следуйте
инструкции `.claude/commands/sdd.specify.md`.
